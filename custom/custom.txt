# Свои домены, IP-адреса и подсети. Из этого файла собираются
# lists/custom*.txt и lists/custom*.lst.
#
# По одной записи на строку; всё после "#" считается комментарием:
#
#   example.com          домен вместе со всеми поддоменами
#   203.0.113.7          IP-адрес (в списке станет 203.0.113.7/32)
#   198.51.100.0/24      подсеть IPv4
#   2001:db8::/32        подсеть IPv6
#
# Регистр, префиксы "domain:" и "full:", "*." и точки по краям не важны;
# кириллические домены можно писать как есть. Порядок и дубликаты тоже не
# важны: при сборке записи сортируются, а лишние поддомены и вложенные
# подсети убираются. Строка, которую не удалось разобрать, останавливает
# сборку с указанием её номера.
